# Ondervraagstijl — Anato Flash

Vier richtingen (per regio of alles samen):

1. **Spier → O / I / F / N** — Origo, Insertie, Functie, Bezenuwing
2. **Zenuw → spier(en)** — welke spieren bij die zenuw
3. **Origo → spier(en)** — welke spieren bij die origo
4. **Insertie → spier(en)** — welke spieren bij die insertie

## Regio's (alle notitiebladen)

| Topic | Blad |
|---|---|
| OA ventraal | Flexoren onderarm |
| OA dorsaal | Extensoren onderarm |
| BA ventraal | Biceps-groep |
| BA dorsaal | Triceps |
| Schouder | Rotator cuff + deltoideus + teres major |
| Schoudergordel | Pectoralis / subclavius / serratus |
| Posterieur rug-schouder | Trapezius / latissimus / rhomboidei / levator |
| Diepe rug schuin | Spinocostal / spinotransversaal / transversospinaal |
| Diepe rug recht | Erector spinae + korte diepe |
| Posterieur capitis | Suboccipitale spieren |
